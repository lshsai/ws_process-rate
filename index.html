      계산 방식 (선형 보간법 적용)
      1단지의 현재 공정률을 2단지는 언제 달성했었는지 계산하여 공사 시차 추정
      $$추정 지연일 = (P_{target} - P_0) \times \frac{\Delta D}{\Delta P}$$
      - $P_{target}$ : 1단지의 현재 공정률
      - $P_0$ : 2단지의 직전 달 공정률
      - $\Delta D$ : 지난 - 이번 공지 사이의 일수
      - $\Delta P$ : 그 기간 동안 2단지가 상승한 공정률

      계산 방식 (계절 가중치 적용)
      과거 실적 기반 공사 속도를 도출한 뒤,
      계절별 제약 조건(장마, 동절기 등)을 가중치로 적용하여 완공 시점을 추정
      추후 실제 데이터가 공시되면 해당 기간의 예측값은 실제값으로 자동 대체, 계산
      $$P_{future} = P_{now} + \sum (R_{base} \times W_{m})$$
      - $P_{future}$ : 미래 특정 시점의 예상 공정률
      - $P_{now}$ : 현재까지 확인된 최신 공정률
      - $R_{base}$ : 날씨 제약이 없는 기준 1일 공정 증가율
      - $W_{m}$ : 월별 기후 가중치
        · 0.9 적용 : 6월(중순 이후 장마 시작)
        · 0.8 적용 : 7, 8월 (장마)
        · 0.7 적용 : 12, 1, 2월 (동절기)
      - 추정 그래프 기준일 : 매달 1일
