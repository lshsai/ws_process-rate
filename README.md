# [왕숙 푸르지오 월별 공사 현황 대시보드]

## 공사 진행 현황 대시보드의 주요 화면 구성과 데이터 산출 기준 안내

---

## 1. 단지별 당월 공정률 및 현장 공사 내역

* 최신 공정률: 'LH 청약센터' 공시 자료 사용, 단지별 당월 누적 공정률 표시
* 현장 공사 내역: '푸르지오 홈페이지' 자료 사용, 골조·마감 등 세부 공사 항목 표시

---

## 2. 월별 공정률 및 전월 대비 증가율 그래프

* 전체 공정률 추이: 착공 ~ 현재까지의 단지별 누적 공정률을 꺾은선 그래프로 표시
* 전월 대비 증가율: 직전 ~ 당월 상승한 공정률 수치(%p)를 막대그래프로 비교

---

## 3. 단지 간 공정 시차(일수) 계산 (선형 보간법)

* 산출 방식: 1단지의 현재 공정률을 2단지가 달성했던 과거 시점을 역산하여 단지 간 공정 시차(일수) 계산
* 참고 및 주의사항: 과거 실적 데이터를 바탕으로 한 단순 산술적 계산값이며, 현장 세부 공정에 따른 실제 시차와는 차이가 있을 수 있음

---

## 4. 계절 가중치 기반 공정률 100% 달성 시점 추정일 계산

* 산출 방식: 과거 공사 속도에 기후 가중치를 적용하여 공정률 100% 도달 예상일 계산
* 장마철(6-8월) 및 동절기(12-2월) 가중치 차등 적용
* 참고 및 주의사항: 기후 가중치를 적용한 단순 계산값, 매월 실제 데이터가 입력되면 수치가 자동으로 보정
